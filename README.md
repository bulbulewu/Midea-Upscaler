## 🚀 Quick Start (Local PC)

### Windows
1. Double-click `start_windows.bat`.
2. App runs at `http://127.0.0.1:5000`.

### Linux / macOS
```bash
chmod +x start.sh
./start.sh
```

1. Open PowerShell inside `Midea-upscaler by Munajat_v3`:
   ```powershell

   ```

   ```bash
   git init
   git add .
   git commit -m "Release v3: Multi-marketplace engine by Munajat International"
   git branch -M main
   git remote add origin https://github.com/bulbulewu/Midea-Upscaler.git
   git push -u origin main --force
   ```
3. On Render.com, select your repo and click **Deploy web service**!
