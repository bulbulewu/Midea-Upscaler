How keys work: generate a key for a user's email → send them the key → they register (or already have an account) with that same email → 🔑 Activate Key. The key becomes Used, and their account gets full access until today + the key's period, with the key's daily limit.

    
Email binding: a key activates ONLY for the email it was generated for — it cannot be shared or resold to another account.

    
Daily limits: while a non-admin user is logged in with an active trial/license, each video job and metadata analysis counts once per day. Expired users are asked to activate a key. Admins, logged-out use, and the not-set-up state are never limited.

    
Where data lives: data/auth_store.json inside the app folder (passwords only as salted hashes). Recovery: if the admin password is lost, delete data/auth_store.json and data/auth_store.json.secret — all accounts reset and first-run setup appears again. The app itself is never locked by this: with no store file it runs openly, exactly like v7.
